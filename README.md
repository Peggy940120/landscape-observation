# 森序｜景觀基地觀察簿

第五週 Vibe Coding 作業：整理景觀基地現況、問題與潛力，連結初步設計策略。

## 使用

直接開啟 index.html 即可使用。正式作業建議依講義發布至 GitHub Pages，再以相同網址持續使用，讓瀏覽器保存資料。首次內含明確標示的通用示範資料，並非實際基地調查。

## GitHub Pages 發布

1. 登入 GitHub，建立 Public 儲存庫，建議名稱 `landscape-observation`。
2. 在儲存庫選 Add file → Upload files，將本資料夾內的 index.html、SPEC.md、README.md 上傳到根目錄，按 Commit changes。不要只上傳 zip。
3. Settings → Pages → Source 選 Deploy from a branch；Branch 選 main；目錄選 / (root)，按 Save。
4. 等部署完成，使用 Pages 顯示的公開網址開啟作品並測試新增、篩選與匯出。
5. 交給老師的是公開的網頁網址。SPEC.md 是規格書，可依課程繳交欄位一併提供。講義未提供另外的課程繳交平台或截止時間，需以實際課程公告為準。

## 資料與限制

不需要 API key。資料存在目前裝置及網址的瀏覽器 localStorage，不會自動傳上網或跨裝置同步。定期使用「備份資料」下載 JSON；更換裝置後可匯入。直接開啟本機檔案與 GitHub Pages 是不同來源，需自行匯出及匯入資料。初步策略仍需現場調查及專業查證。

## 檔案

- index.html：可直接執行的網頁。
- SPEC.md：需求討論紀錄、功能規格、驗收標準及可攜 Prompt。
- README.md：使用與發布方式。
